# Blade / Blade Runner — Genesis scene

Original fan-art clip inspired by the Sega Genesis games Generations Lost and X-Men 2: Clone Wars. Blade and a replicant hunter face a vampire and a rogue replicant in a dystopian city.

Final video: `blade-runner-genesis-3s.mp4`. Exactly 3 seconds, 30 fps, 1280 × 896. Original synthesized ambience and effects.

Artwork: built-in imagegen. Generated background and transparent animation atlas retained as `city.png` and `sprites.png`. Prompts retained in `prompts.json`.

Rebuild: `node output/blade-runner-genesis/render.mjs` from the repository root. Requires Node.js and FFmpeg on PATH. The renderer composites supplied sprite cels, weather, lighting, effects, and audio; no external packages needed.

Visual reference: [X-Men 2: Clone Wars screenshots](https://gamefabrique.com/games/x-men-2-clone-wars/).
