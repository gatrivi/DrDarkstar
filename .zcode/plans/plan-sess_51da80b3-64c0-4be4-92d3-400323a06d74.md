# Super Smash Cousins: real spritesheets + all-pixel-rain presentation

## What exists today
- Fighters are **procedurally painted** 24×32 canvas sheets (`AndyFighter.js`, `Eliseo.js`); the new PNGs in `assets/andy|eliseo|simon/` are unwired, and all have **baked-in checkerboard backgrounds** that must never reach the rain sampler.
- Engine hook `applySheet({sheet, pw, ph, frames})` already exists; `AnimatedSprite` expects **one horizontal row** of uniform frames.
- The Blade demo's performance solution (`src/game/night/WorldRain.js` + `NightStage.js`): half-res scene capture with `willReadFrequently`, quantized 65536-entry color palette, software rasterization of all drops into one reusable ImageData + a **single `putImageData`/frame**, frame dedup + warm-up passes, and throttling per-fighter rain (`maxDrops`) when world rain is on.
- **Found bug:** `AndyFighter.startMove()` uses the module-level Andy `FRAME_INDEX` instead of `this.frameIndex`, so Eliseo's attacks (`aa`/`smash`/`tilt`/`roll` poses) set frame `NaN` → empty mask → **she turns invisible during every attack**. Will fix.

## Changes

### 1. New `src/game/smash/SheetLoader.js`
- `loadSheet(src, {cols, rows, poses, frameSize})`: loads PNG → offscreen canvas → **checkerboard removal** (flood fill from image borders against the two gray checker tones, tolerance-based, so only background-connected gray is cleared — sprite whites like Andy's sword survive) → slice cells (handles non-integer cells, e.g. Simon 1774×887 4×2) → per-cell alpha-bbox **trim + alignment** into uniform square frames (uniform scale from content height, bottom-aligned feet baseline, horizontal bbox center) → returns a one-row sheet `{sheet, pw, ph, frames}` ready for `applySheet()`. Asserts borders are fully transparent (warn on leftovers).
- `tintSheet(sheetInfo, rgba)`: composite `source-atop` recolor for the DUMMY variant.

Pose maps (slot order from the READMEs):
- **Andy 4×4 (16):** idle, walk1, walk2, dash, jump, punch1–3, windup, swing, serve, super, whistle, block, hurt, victory. Wire the `hurt` frame during hitstun (free feel-win; block/victory ride along unused).
- **Eliseo 4×4 (16):** idle, walk1, walk2, dash, jump, roll, aa, tilt, charge→smash, smash, follow-through→smash, summon→tilt, possession→smash, block, hurt, victory (explicit frameIndex handles duplicates).
- **Simon 4×2 (8):** idle; paddle jab→punch (J); low sweep→tilt; iron-bar windup→smash (K); human ladder→jump (his recovery); pitbull mount→summon (I, reuses `Retriever` with a gray "pitbull" tint variant); siesta→super (U nap buff); paddle serve→serve (L, spawns the existing pong ball).

### 2. New `src/game/smash/Simon.js`
`SimonFighter extends AndyFighter` (Eliseo pattern): pose index, `SIMON_MOVES` table, `load()` via SheetLoader; fallback to a tinted procedural sheet if the PNG fails.

### 3. New `src/game/smash/StageArt.js` (theme: **neon night city**, matching the repo's Night Hunters mood)
- `buildBackground(w,h)`: pixel-art offscreen canvas — night sky, stars, moon, two parallax-ish skyline layers with lit windows, distant neon signs (drawn once; static like NightStage, plus a slow patrol-light sweep at draw time).
- `buildPlatform(p)`: metal floating slab — riveted plating, neon-cyan lit top edge, hazard stripes, stepped understructure; repainted on resize.

### 4. `SmashStage.js` — full-world pixel rain (the Blade solution)
- Refactor render into `drawWorld(ctx, solid)` (bg → platform → shadows → fighters → projectiles → summons → fx), mirroring `NightStage`.
- Add half-res `scene` canvas + `WorldRain`; when enabled (default ON): draw world into `scene` (fighters near-solid), `worldRain.step(scene, delta, audio, frame)`, `worldRain.draw(ctx)`, overlay the per-fighter trails canvas + throttled focused rains (`maxDrops 2400/1600` vs 8000) so bodies stay readable. When toggled off: classic path (flat bg → ambient rain → translucent fighters → focused rains).
- Player can now be `simon`; swap cycle **Andy → Eliseo → Simon** (dummy = a *different* cousin's tinted sheet, keeping the red DUMMY identity).
- Per-fighter HUD buff label (Andy "VEGAN POWER", Simon "SIESTA POWER").

## Why this shape
- Reuses every existing seam (`applySheet`, `CollisionRain`, `WorldRain`, NightStage's render pattern) instead of inventing new plumbing.
- The flood-fill + trim/align step directly answers all three asset READMEs' warnings (checkerboard in the mask, poses crossing cell bounds, Simon's size variance).
- World rain ON by default with the exact Blade optimizations (half-res, palette quantization, single putImageData, throttling) and an OFF toggle as the escape hatch.
