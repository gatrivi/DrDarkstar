# Dr Darkstar idle transitions

`idle-inbetweens-v1.png` contains eight newly generated transition drawings, read left to right across the top row, then the bottom row.

1. Cape unfurls.
2. Hand extends; staff seed appears.
3. Shaft grows through the grip.
4. Hook and dot materialize.
5. Cape billows around the stationary staff.
6. Staff dissolves.
7. Hand withdraws with the remaining fragment.
8. Cape settles.

Generated with built-in imagegen from the original character JPEG. Exact prompt: `generation-prompt.txt`. Black background is intentional and works with the existing `keyBlack` function. These are proposed inbetweens, with cleaner contours than the original; they are not substituted into the game.

Open `/cape-keyframes.html` through the project server to animate and scrub the original nine poses and the eight proposed drawings. The Rain Studies idle now includes all nine existing original poses instead of cycling only the first three. Original source images are untouched.
